                                         **   Family Tree Input and Display **

Requirements : 

1.Operating system : Ubuntu Linux
2.Compiler : GCC , Which compiles C code into an executable program
3.Memory checking tool: Valgrind, which helps in memory leaks.

Compiling the Program : 
C source must be compiled  before it can run.Use this command while compiling : gcc -std=c11 -Wall -Wextra -Wpedantic family_tree.c -o family_tree Gcc - C compiler Family_tree.c - your source C code
-o family_tree - Names the compiled executable family_tree

Running the program : Use this command : ./family_tree — this runs the compiled  program. 


Project description :Here in this project it deals with c programming  that  takes seven people from  across three generations  and points them using the pointers.Program collects two pieces of information about each person. It displays the family relationships.

Project features: 
1.collects the names and ages of seven family members
2.connects family members using pointers
3.Displays the details of each person and their family  relationships.
4.Allocates and freshens memory for the family members.

Program Output :
The program will ask you to enter the names and ages of seven family members. After you enter all the information, it will display the family tree and their relationships.
